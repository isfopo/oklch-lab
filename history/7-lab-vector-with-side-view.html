OKLCH Lab

Different control designs for the same OKLCH color. Every version edits one shared color, which also sets the page background, so you can switch versions and compare them directly. Chroma is either absolute (0 to 0.37, the same scale for every hue) or relative (a percentage of the most that hue can reach on screen at the current lightness, so every hue feels equally intense). Lightness is either absolute (linear) or relative, which gives more slider travel to the lightness band where the current hue is most colorful, more so the more chroma you pick.
